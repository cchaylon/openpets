# 启动命令

环境：Windows + Node 22（nvm）+ pnpm 11.0.8 + 代理 `127.0.0.1:17890`。
当前开发分支：`dev_new`。

## 命令

```powershell
# 1. 拉代码（直连不通就走代理）
git clone -b dev_new --depth 1 -c http.proxy=http://127.0.0.1:17890 `
  -c https.proxy=http://127.0.0.1:17890 https://github.com/cchaylon/openpets.git .

# 2. Node（pnpm 11 要求 >=22.13，根 engines 只写 >=20）
nvm install 22
nvm use 22.20.0

# 3. pnpm
corepack enable pnpm

# 4. 依赖（必须带代理，否则 Electron 预编译包下载失败）
$env:HTTP_PROXY='http://127.0.0.1:17890'
$env:HTTPS_PROXY='http://127.0.0.1:17890'
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
pnpm install --registry=https://registry.npmmirror.com

# 5. 启动
pnpm dev:desktop
```

成功标志：终端出现 `{"level":"info","scope":"app","message":"ready",...}`，托盘出现图标，桌面右下角出现宠物。
日志：`%APPDATA%\DeskPet\logs\deskpet.log`。状态：`%APPDATA%\DeskPet\deskpet-state.json`。停止：`Ctrl+C`。

## 可选变体

```powershell
pnpm dev:desktop:control-center                # 前端热更新，占用 127.0.0.1:5173
pnpm --filter @deskpet/desktop dev:electron    # 只改主进程，跳过前端构建
pnpm check                                     # 类型检查 + 完整构建
pnpm package:desktop                           # 打包到 apps/desktop/dist-electron
```

注意：

- `pnpm dev:desktop` 每次都会先执行 `build`（主进程 `tsc` + 前端 `vite build`），首次启动较慢。
- 应用是单实例的；重复启动会直接唤起已运行实例的控制中心。
- 关闭控制中心窗口不会退出应用，退出统一走托盘菜单或宠物右键菜单。
