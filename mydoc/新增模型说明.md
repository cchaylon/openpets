# 新增模型说明

本文以「皮卡丘」为例，说明在 DeskPet 中新增一个宠物模型的完整流程。
当前版本不需要改代码：把宠物做成符合规范的宠物包，然后在控制中心导入即可。

> 版权提醒：皮卡丘是任天堂 / Game Freak 的受版权保护角色。自己本地测试没有问题；
> 如果要公开分发或商业化，请先确认你拥有相应的美术授权，或改用原创角色。

## 一、先理解一个宠物包

DeskPet 直接兼容 OpenPets 的宠物包格式。一个最小宠物包只有两个文件：

```text
pikachu/
├── pet.json            # 宠物元数据
└── spritesheet.webp    # 精灵图（也可以是 spritesheet.svg）
```

导入后，文件会被复制到应用数据目录：

| 平台 | 宠物目录 |
| --- | --- |
| Windows | `%APPDATA%\DeskPet\pets\pikachu` |
| macOS | `~/Library/Application Support/DeskPet/pets/pikachu` |
| Linux | `~/.config/DeskPet/pets/pikachu` |

应用只读取这两个文件，不会执行宠物包里的任何脚本。

## 二、编写 pet.json

皮卡丘的 `pet.json` 示例：

```json
{
  "id": "pikachu",
  "displayName": "皮卡丘",
  "description": "一只会放电的黄色电气鼠。",
  "spritesheetPath": "spritesheet.webp",
  "spriteVersionNumber": 2
}
```

字段规则：

| 字段 | 要求 |
| --- | --- |
| `id` | 必填。小写字母、数字、下划线或短横线，1–64 位；不能是 `builtin`；导入后作为目录名，建议不要随意修改 |
| `displayName` | 必填。1–80 个字符，显示在宠物卡片和菜单里 |
| `description` | 必填。1–500 个字符，显示在宠物卡片里 |
| `spritesheetPath` | 必填。`spritesheet.webp` 或 `spritesheet.svg`，必须与实际文件一致 |
| `spriteVersionNumber` | 可选。写 `2` 表示 V2 图集（推荐）；不写表示 V1 |

注意：

- `id` 不需要和文件夹名一致，导入时以 `pet.json` 里的 `id` 为准。
- 同一个 `id` 已安装时，再次导入会失败，需要先移除旧宠物。
- 推荐统一使用 V2（`spriteVersionNumber: 2`），动画行更全，也是内置宠物的格式。

## 三、制作精灵图

### 1. 画布与网格

精灵图是**一张静态的帧网格**，不是动图 WebP。

| 项目 | 数值 |
| --- | --- |
| 单帧尺寸 | `192 × 208` 像素 |
| 列数 | 8 列 |
| V1 行数 | 9 行 → 画布 `1536 × 1872` |
| V2 行数 | 11 行 → 画布 `1536 × 2288`（推荐） |
| 背景 | 必须透明 |
| 格式 | WebP（推荐）；或受限静态 SVG |

第 `row` 行、第 `col` 列的帧，在整张图上的位置是：

```text
x = col × 192
y = row × 208
```

### 2. 行与动作的对应关系

DeskPet 会按下面的行号播放动画。皮卡丘的每一行都按这个规划来画：

| 行 | 动作 | 使用帧数 | 时长 | 播放方式 | 触发场景 |
| --- | --- | --- | --- | --- | --- |
| 0 | 待机 | 6 | 5.5 s | 循环 | 默认状态；控制中心卡片预览也播这一行 |
| 1 | 向右跑 | 8 | 1.06 s | 循环 | 向右拖拽宠物时 |
| 2 | 向左跑 | 8 | 1.06 s | 循环 | 向左拖拽宠物时 |
| 3 | 挥手 | 4 | 0.7 s | 播 2 次 | 单击宠物 |
| 4 | 跳跃 | 5 | 0.84 s | 播 2 次 | 右键菜单「跳跃」 |
| 5 | 失败 / 沮丧 | 8 | 1.22 s | 播 2 次 | 预留，当前菜单未使用 |
| 6 | 等待 | 6 | 1.01 s | 循环 | 右键菜单「等待」 |
| 7 | 工作 / 忙碌 | 6 | 0.82 s | 循环 | 预留 |
| 8 | 思考 / 审查 | 6 | 1.03 s | 循环 | 右键菜单「思考」 |
| 9–10 | 视线方向 | 16 | — | 静态 | V2 保留，当前 DeskPet 未启用 |

说明：

- 每行从第 0 列开始连续放帧，剩余格子留空即可。
- 行 5、7 和行 9–10 当前没有入口，但建议保留并画好，后续加动作时不用重做图集。
- V1 只有 9 行，只支持行 0–8；如果需要视线方向，用 V2。
- 单帧里的人物建议**底部居中**：脚底接近每格底部（约 y=200），水平中心在 x=96。
  宠物窗口是按底部对齐的，这样切换动作时不会上下跳。
- 不要在图里画投影，应用会自动加一层柔和的投影。
- 每一帧的构图、大小、朝向要一致；向左跑和向右跑建议画成两套独立帧，
  而不是依赖水平翻转。

### 3. 皮卡丘的逐行画法示例

1. **待机（行 0）**：正面站立，耳朵轻微摆动、尾巴上下晃、偶尔眨眼，6 帧循环。
2. **向右跑（行 1）**：身体朝右，前倾，双腿交替，尾巴向后飘，8 帧循环。
3. **向左跑（行 2）**：与行 1 镜像构图，但重新画朝向细节（脸、尾巴），8 帧循环。
4. **挥手（行 3）**：正面站立，一只前爪抬起挥动，4 帧，播两次后回到待机。
5. **跳跃（行 4）**：下蹲 → 起跳 → 空中 → 落地 → 回正，5 帧。
6. **失败（行 5）**：耳朵下垂、身体缩小、表情沮丧，8 帧。
7. **等待（行 6）**：小幅左右张望或抖脚，6 帧循环。
8. **工作（行 7）**：快速小幅动作，比如连续挥爪或原地小跑，6 帧循环。
9. **思考（行 8）**：歪头、摸下巴或头顶冒问号，6 帧循环。
10. **视线（行 9–10）**：V2 的 16 个方向各一格，按 22.5° 递增；当前版本不播放，
    可以把待机帧复制进去占位。

### 4. 导出要求

- 用 Photoshop、Aseprite、Krita 等工具按 `1536 × 2288` 建画布，开启透明背景。
- 导出为 **静态 WebP**：单页、包含 Alpha、无损或高质量。
- 不要导出为动画 WebP（多页会被拒绝）。
- 文件大小上限 100 MB；正常宠物图集远小于这个值。
- 如果用 SVG：只支持静态、自包含的矢量子集，且必须精确匹配
  `width="1536"`、`height="2288"`、`viewBox="0 0 1536 2288"`（V1 则为 1872）。
  普通设计工具导出的 SVG 往往包含 CSS，建议直接使用 WebP。

### 5. 自检图片

在仓库的 `apps/desktop` 目录下执行（使用项目已安装的 sharp）：

```bash
cd apps/desktop
node -e "import('sharp').then(async ({default: sharp}) => { const m = await sharp('D:/pets/pikachu/spritesheet.webp').metadata(); console.log({ width: m.width, height: m.height, hasAlpha: m.hasAlpha, pages: m.pages }); })"
```

应输出：

```text
{ width: 1536, height: 2288, hasAlpha: true, pages: 1 }
```

## 四、导入应用

### 方式 A：文件夹导入

1. 打开托盘菜单 →「打开控制中心」。
2. 进入「宠物」页。
3. 点击「导入文件夹」，选择包含 `pet.json` 和 `spritesheet.webp` 的
   `pikachu` 文件夹。
4. 导入成功后，卡片会出现在「我的宠物」里。
5. 点击「设为默认」，桌面宠物立即切换为皮卡丘。

### 方式 B：ZIP 导入

ZIP 可以有两种结构，二者都支持：

```text
# 文件在 ZIP 根目录
pikachu.zip
├── pet.json
└── spritesheet.webp

# 或文件在一个顶层文件夹里
pikachu.zip
└── pikachu/
    ├── pet.json
    └── spritesheet.webp
```

PowerShell 打包示例：

```powershell
# 只打包文件夹内容（文件位于 ZIP 根目录）
Compress-Archive -Path .\pikachu\* -DestinationPath .\pikachu.zip -Force

# 或连同文件夹一起打包（文件位于一层目录下）
Compress-Archive -Path .\pikachu -DestinationPath .\pikachu.zip -Force
```

然后在控制中心点击「导入 ZIP」选择该文件。

ZIP 限制：

- 只允许 `pet.json` 和一张精灵图，不能混入 `.DS_Store`、`__MACOSX`、
  说明文档、多个图集或预览图。
- 允许文件在根目录，或在一个顶层文件夹下；不能有多层嵌套。
- 单个条目不能是绝对路径、包含 `..`、反斜杠或重复/大小写冲突名称。
- 整个 ZIP 最多 3 个条目（可选的一层目录条目 + 两个文件）。
- 精灵图必须是 `spritesheet.webp` 或 `spritesheet.svg`。

## 五、导入时应用会检查什么

导入不是简单复制，应用会先校验，失败时会在控制中心弹出具体原因：

| 检查项 | 失败示例 |
| --- | --- |
| `pet.json` 是否存在、是否为合法 JSON | 缺少 `pet.json` |
| `id`、`displayName`、`description` | `id` 大写、含空格、叫 `builtin`、名称为空 |
| 图集文件名 | `sprite.webp`、同时包含 webp 和 svg |
| WebP 尺寸 | 要求 `1536 × 2288`（V2）或 `1536 × 1872`（V1） |
| WebP 透明通道 | `hasAlpha=false` |
| WebP 页数 | 动画 WebP 的 `pages > 1` |
| WebP 可解码 | 文件损坏 |
| SVG 规范 | 含 CSS、外部引用、文本或尺寸不匹配 |
| 大小限制 | `pet.json` 超过 128 KB；WebP 超过 100 MB；SVG 超过 8 MB |
| 重复 ID | 已经导入过 `pikachu` |

常见错误与原因：

| 报错 | 原因 |
| --- | --- |
| `spritesheet.webp 尺寸必须是 1536x2288。` | 图集是 V1 尺寸，但 `pet.json` 写了 `spriteVersionNumber: 2`；或反之漏写版本 |
| `spritesheet.webp 必须包含透明通道。` | 导出时丢了 Alpha |
| `spritesheet.webp 只能包含一张图。` | 导出成了动画 WebP |
| `已存在同 ID 的宠物：pikachu` | 先移除旧的皮卡丘再导入 |
| `ZIP 包含不支持的文件：xxx` | ZIP 里混入了额外文件 |
| `缺少 pet.json。` | ZIP 选错了层级，或打包时漏了文件 |

## 六、替换内置宠物（可选）

如果想让皮卡丘成为**随应用内置**的宠物，而不是用户导入：

1. 准备一张 V2 图集（`1536 × 2288`，带透明通道）。
2. 替换：
   `apps/desktop/assets/default-pet-spritesheet.webp`
3. 修改 `apps/desktop/src/built-in-pet.ts` 里的显示信息：

   ```ts
   export const builtInPet: PetSummary = {
     id: BUILT_IN_PET_ID,
     displayName: "皮卡丘",
     description: "一只会放电的黄色电气鼠。",
     builtIn: true,
     spriteVersion: 2,
     spriteUrl: petSpriteUrl(BUILT_IN_PET_ID),
   };
   ```

4. 重新构建并启动：

   ```bash
   pnpm dev:desktop
   ```

注意：

- 内置宠物只有一只，替换后就看不到原来的 Hoodie Cat 了。
- 内置宠物不能被移除。
- 当前版本没有「多只随包内置宠物」的机制；如果既要内置多只，建议改为把宠物放在
  `assets` 下并在首次启动时复制到用户宠物目录，这需要额外改代码。
  一般需求直接用「导入宠物」即可。

## 七、验收清单

导入皮卡丘后，按下面逐项确认：

- [ ] 控制中心「宠物」页出现「皮卡丘」卡片，预览有动画。
- [ ] 点击「设为默认」，桌面宠物切换为皮卡丘。
- [ ] 待机时循环播放第 0 行。
- [ ] 单击宠物播放挥手（第 3 行），结束后回到待机。
- [ ] 左右拖拽宠物时播放对应方向的跑动（第 1/2 行）。
- [ ] 右键菜单「跳跃」「思考」「等待」都能播放对应动作并回到待机。
- [ ] 拖动后位置能保留，重启应用后仍在原位置。
- [ ] 换一个宠物大小，皮卡丘缩放正常且不跑出屏幕。
- [ ] 「移除」后卡片消失，桌面回退到内置宠物。
