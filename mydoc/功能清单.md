# 功能清单

DeskPet 是在 OpenPets 基础上精简重写的桌面宠物应用，保留「桌面宠物核心 + 宠物选择 + 设置」，
并接入 AI 语音服务提供语音与文字对话。
技术栈为 Electron + React + Tailwind，托盘优先、无主窗口。

## 功能总览

| 序号 | 大功能 | 一句话说明 |
| --- | --- | --- |
| 1 | 桌面宠物核心 | 透明置顶宠物窗口、精灵图动画、拖拽与点击交互 |
| 2 | 宠物选择与导入 | 内置宠物 + 本地宠物包（文件夹 / ZIP）导入、切换、移除 |
| 3 | 设置 | 大小、启动显示、始终置顶、位置重置、开机自启 |
| 4 | 托盘与控制中心 | 托盘菜单入口 + 两页式 React 管理界面 |
| 5 | AI语音对话 | 长按 Alt 语音对话、点击宠物文字对话、文字气泡回答 |
| 6 | 运行保障与发布 | 日志、状态持久化、安全边界、跨平台打包 |

## 1. 桌面宠物核心

应用的主体验。

- **宠物窗口**：透明、无边框、不可缩放 / 最小化、跳过任务栏、默认置顶；
  窗口透明背景不拦截鼠标，只有宠物点击区响应。
- **尺寸**：小 / 中 / 大 / 特大四档（0.5 / 0.75 / 1 / 1.25），切换后立即缩放并保持右下角位置。
- **位置**：默认落在主屏幕右下角；拖拽时按最近显示器工作区夹取，跨屏移动不会跑出屏幕；位置自动记忆，
  可在设置里重置。
- **动画反应**：idle、向右跑、向左跑、挥手、跳跃、失败、等待、运行、审查共 9 种精灵图状态；
  拖拽时按方向切换跑动，松手回到 idle，临时反应播完后自动回落。
- **宠物包兼容**：支持 OpenPets 宠物格式的 v1（1536×1872）与 v2（1536×2288）图集，帧尺寸 192×208。
- **内置宠物**：Hoodie Cat 随应用提供，离线可用，始终可作为兜底选择。

## 2. 宠物选择与导入

- **宠物列表**：卡片展示内置与已导入宠物，含缩略动画、版本标记、「内置 / 已导入」「使用中」状态。
- **切换**：一键「设为默认」，立即刷新桌面上的宠物。
- **导入文件夹**：选择本地目录，校验后安装到用户目录。
- **导入 ZIP**：选择只含 `pet.json` 与一张精灵图的 ZIP，校验后解压安装。
- **移除**：删除非内置宠物，同时清理本地文件；内置宠物不可删除。
- **格式校验**：ID 与文案长度、WebP 格式 / 尺寸 / 透明通道、受限 SVG 结构、ZIP 路径与条目数量、
  文件大小上限，全部通过后才落盘。
- **原子安装**：先写临时目录再重命名，失败自动清理；同 ID 宠物不允许重复安装。
- **自动恢复**：启动时扫描安装目录，忽略非法或损坏的宠物目录。

## 3. 设置

- **外观**：宠物大小四档，修改即时生效。
- **宠物窗口**：启动时显示宠物、始终置顶、重置位置。
- **系统**：开机自启动（受系统与桌面环境支持情况限制）。
- **关于**：版本、当前宠物、桌面显示状态、许可证。

## 4. 托盘与控制中心

- **托盘菜单**：当前宠物、显示 / 隐藏宠物、打开控制中心、退出。
- **宠物交互入口**：双击宠物或右键选择「打开控制中心」；右键菜单还提供挥手、跳跃、思考、等待、隐藏、退出。
- **控制中心**：单窗口 React 界面，左侧栏切换「宠物」「设置」两页；顶部显示宠物是否在桌面及当前宠物名。
- **即时反馈**：所有设置与切换操作即时落盘并通过快照广播回推界面，操作结果以 Toast 提示。
- **单实例**：重复启动会唤起已运行实例的控制中心，而不是再开一个应用。

## 5. AI语音对话

- **服务配置**：设置页可启用 / 关闭 AI语音对话，填写 OTA 地址；设备 ID 由本机唯一标识动态生成（固定 MAC 格式），同一台电脑保持不变。
- **语音对话**：全局长按 Alt 说话，松开后由 AI 完成识别、思考与回答；对话期间宠物上方显示「对话中」状态图标。
- **文字对话**：单击宠物（或右键菜单「AI语音对话」）展开文字输入面板，Enter 发送、Esc 关闭；双击宠物仍打开控制中心。
- **文字回答**：回答按句流式显示在宠物旁边的气泡中；文字面板打开时显示在会话记录里，用户与助手消息分左右气泡。
- **语音播放**：AI 下发的 Opus 音频在宠物窗口内解码并播放；新的对话会先打断当前播报。
- **连接管理**：按需连接、自动 OTA 获取 WebSocket 地址与 Token；OTA 在 8002 / 8003 之间自动回退，未配置 WebSocket 地址时回退到同主机 8000 端口；未绑定设备时提示激活码；配置变更会重置连接。
- **协议细节**：见 `mydoc/小智语音对接说明.md`。

## 6. 运行保障与发布

- **日志**：JSON 行日志写入 `logs/deskpet.log`，超过 2 MiB 自动轮转为 `deskpet.log.1`。
- **状态持久化**：`deskpet-state.json` 采用临时文件 + 重命名的原子写入；文件损坏时隔离为
  `.corrupt-<时间戳>` 并回退默认值。
- **安全边界**：两个窗口均启用 `contextIsolation + sandbox`，禁用 Node 集成；控制中心有严格 CSP；
  拒绝 `window.open` 与外部导航；主进程 IPC 校验发送方；宠物 ZIP 与 SVG 做路径 / 结构白名单校验。
- **跨平台打包**：macOS（DMG / ZIP）、Windows（NSIS）、Linux（AppImage / DEB），ASAR 打包并解包原生依赖。
- **质量脚本**：`pnpm check`（两套 tsconfig 类型检查 + 完整构建）、`pnpm package:desktop`。

## 当前不包含的能力

以下 OpenPets 能力在本次精简中已移除，不在当前范围内：

- 编码 Agent 集成（Claude Code、Cursor、Zed、MCP、CLI 等）与本地 IPC 服务 / 租约模型
- 插件平台、插件 SDK、官方 / 社区插件与在线目录
- 宠物在线目录浏览、远程 ZIP 下载、深链接安装、Codex 宠物导入
- 宠物服装（outfit）与换装日程
- 通用 AI 助手与多模型提供商配置（当前仅接入 AI语音对话）
- 多语言界面、Teams 组织模式、签到、自动更新检查
