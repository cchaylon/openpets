# 项目工程结构

DeskPet 是在 OpenPets 基础上精简重写的桌面宠物应用，保留「桌面宠物核心 + 宠物选择 + 设置」，
并接入 AI 语音服务提供语音 / 文字对话。
仓库是 pnpm + TypeScript 的 monorepo，只有一个可部署应用 `apps/desktop`，技术栈为
Electron 42 + React 19 + Tailwind 3 + Vite 8。

## 渲染层与 preload

- 控制中心只有两个页面：`宠物`（PetsPage）与 `设置`（SettingsPage），路由由 `App.tsx` 的本地 state 管理，无路由库。
- `control-center-preload.cjs` 暴露 `window.deskpet`：`getSnapshot`、`updatePreferences`、`setDefaultPet`、
  `importPetFolder`、`importPetZip`、`removePet`、`resetPetPosition`、`onSnapshotChanged`。
- `pet-preload.cjs` 负责宠物窗口的全部交互与媒体能力：把 pointer 事件转成拖拽 / 点击 / 双击 / 右键 IPC；
  渲染对话会话、语音状态与回答气泡；用 WebCodecs + ScriptProcessorNode 采集麦克风并编码为 16 kHz、60 ms Opus 帧上行；
  解码下行 Opus 帧并调度播放；接收 `deskpet:reaction`、`deskpet:motion`、`deskpet:conversation-view` 等主进程事件。
- 两个窗口都启用 `contextIsolation + sandbox`、关闭 `nodeIntegration`，并拒绝 `window.open`；
  宠物窗口只能加载本地 `pet.html`，页面本身不执行任何脚本（`script-src 'none'`）。

## IPC 契约

| 通道 | 方向 | 说明 |
| --- | --- | --- |
| `deskpet:get-snapshot` | 控制中心 → 主进程 | 获取完整快照 |
| `deskpet:update-preferences` | 控制中心 → 主进程 | 更新大小 / 启动显示 / 自启 / 置顶 / AI语音配置 |
| `deskpet:set-default-pet` | 控制中心 → 主进程 | 切换当前宠物 |
| `deskpet:import-pet-folder` / `import-pet-zip` | 控制中心 → 主进程 | 打开系统选择框并安装 |
| `deskpet:remove-pet` | 控制中心 → 主进程 | 删除非内置宠物（含本地目录） |
| `deskpet:reset-pet-position` | 控制中心 → 主进程 | 回到右下角默认位置 |
| `deskpet:snapshot-changed` | 主进程 → 控制中心 | 状态变化广播 |
| `deskpet:drag-start` / `drag-move` / `drag-end` | 宠物 → 主进程 | 基于屏幕光标计算窗口位移 |
| `deskpet:pet-clicked` | 宠物 → 主进程 | 单击切换文字对话（并挥手） |
| `deskpet:open-control-center` | 宠物 → 主进程 | 双击打开控制中心 |
| `deskpet:context-menu` | 宠物 → 主进程 | 弹出宠物右键菜单 |
| `deskpet:chat-send` / `chat-close` | 宠物 → 主进程 | 发送文字 / 关闭对话面板 |
| `deskpet:mic-chunk` / `mic-ended` / `mic-error` | 宠物 → 主进程 | 上行 Opus 帧、录音结束、麦克风错误 |
| `deskpet:conversation-view` | 主进程 → 宠物 | 对话面板、消息、气泡、语音状态 |
| `deskpet:voice-capture-start` / `voice-capture-stop` | 主进程 → 宠物 | 开始 / 停止录音 |
| `deskpet:tts-audio` / `playback-reset` | 主进程 → 宠物 | 下行 Opus 帧 / 打断并清空播放队列 |
| `deskpet:reaction` / `deskpet:motion` | 主进程 → 宠物 | 切换反应动画 / 左右拖动动画 |

主进程对两个窗口的 IPC 都校验 `event.sender`，来源不符直接拒绝。

## 宠物包格式

一个宠物包由 `pet.json` 与一张精灵图组成，兼容 OpenPets 宠物格式。

`pet.json`：

| 字段 | 约束 |
| --- | --- |
| `id` | 小写字母 / 数字 / `_` / `-`，1–64 字符，不能是 `builtin`，也是安装目录名 |
| `displayName` | 非空，最长 80 字符 |
| `description` | 非空，最长 500 字符 |
| `spritesheetPath` | 只能是 `spritesheet.webp` 或 `spritesheet.svg` |
| `spriteVersionNumber` | 可选，若出现只能是 `2` |

图集规格：

| 版本 | 尺寸 | 行数 | 说明 |
| --- | --- | --- | --- |
| v1（无 `spriteVersionNumber`） | 1536×1872 | 9 | 192×208 帧，8 列 |
| v2（`spriteVersionNumber: 2`） | 1536×2288 | 11 | 同上，多两行 |

行序：idle、向右跑、向左跑、挥手、跳跃、失败、等待、运行、审查。
v2 图集共 11 行，当前渲染只使用前 9 行的标准状态。

校验规则：

- `pet.json` ≤ 128 KiB；WebP ≤ 100 MiB，必须是静态、带透明通道、尺寸精确匹配的 WebP，且能完整解码。
- SVG ≤ 8 MiB，只接受白名单元素 / 属性的小型矢量文件：无 CSS、实体、脚本、位图、嵌套命名空间；
  必须声明 `xmlns`、精确 `width/height` 与 `viewBox="0 0 W H"`；引用只能指向本文件内的渐变或裁剪路径。
- ZIP 最多 3 个条目（允许整包多一层目录），只能是 `pet.json` + 一张图集；拒绝绝对路径、`..`、反斜杠、重复文件、
  同时包含 `.webp` 与 `.svg`。

安装行为：

- 目标目录 `userData/pets/<id>`；先解压 / 复制到 `.extract-*` / `.install-*` 临时目录，再 `rename` 到位。
- 已存在同 ID 直接报错；卸载会删除整个宠物目录。
- 启动时扫描 `userData/pets/`，跳过非法目录名与读取失败的宠物。

## 运行时数据

应用名 `DeskPet`（`app.setName`），`userData` 在 Windows 为 `%APPDATA%\DeskPet`，
macOS 为 `~/Library/Application Support/DeskPet`，Linux 为 `~/.config/DeskPet`。

| 路径 | 内容 |
| --- | --- |
| `deskpet-state.json` | `version: 1` + `preferences` + `installedPets`；损坏时重命名为 `.corrupt-<时间戳>` 并回退默认值 |
| `pets/<id>/` | 已安装宠物的 `pet.json` 与精灵图 |
| `logs/deskpet.log` | JSON 行日志；超过 2 MiB 轮转为 `deskpet.log.1` |

`preferences` 字段：`defaultPetId`、`petScale`（0.5 / 0.75 / 1 / 1.25）、`showOnLaunch`、
`launchAtLogin`、`alwaysOnTop`、可选 `petPosition`，以及 `aiVoice`（`enabled`、`otaUrl`）。
设备 ID 不持久化，运行时由本机唯一标识（Windows MachineGuid / macOS IOPlatformUUID / Linux machine-id）哈希成 MAC。

## 构建与打包

| 命令 | 产物 / 行为 |
| --- | --- |
| `pnpm build` | `tsc` 输出主进程到 `apps/desktop/dist/`，Vite 输出前端到 `apps/desktop/dist/renderer/` |
| `pnpm check` | 两套 tsconfig 类型检查 + 完整构建 |
| `pnpm package:desktop` | 先 build，再 `electron-builder` 输出到 `dist-electron/` |

打包范围（`electron-builder.yml`）：`dist/**`、两个 preload、`pet.html`、`assets/**`、`package.json`；
启用 ASAR 并解包 `node_modules/**`（`uiohook-napi` 的预编译二进制依赖此设置）。目标：macOS DMG/ZIP、Windows NSIS、Linux AppImage/DEB；
`appId: dev.deskpet.app`，可执行名 `deskpet`。

## 核心链路

1. **启动**：`main.ts` → 日志 → 状态加载 → 宠物扫描 → 注册 `petdesk-asset` 协议与 IPC → 托盘 → 宠物窗口 → AI语音对话初始化 → 按偏好决定是否显示。
2. **交互**：preload 捕获拖拽 / 点击 / 双击 / 右键 → 主进程移动窗口、切换对话面板或打开控制中心 / 菜单。
3. **切换与导入**：控制中心调用 IPC → `pet-install` 校验并原子安装 → `app-state` 更新 → 快照广播 → 宠物窗口重载内容。
4. **反应动画**：主进程发送 `deskpet:reaction` → `pet.html` 中的 CSS 变量切换行与帧数 → 到时自动回落 `idle`。
5. **AI语音对话**：Alt 按下 → `ai-voice-shortcut` → `ai-voice-conversation` 连接（OTA + WebSocket hello）→ 通知 preload 录音 → Opus 帧上行 → `stt` / `tts sentence_start` 回流文字与音频 → 气泡 / 会话展示并播放。
6. **AI文字对话**：点击宠物 → 展开会话面板 → 输入文字 → `listen detect` → 流式 `sentence_start` 拼成回答 → 面板内左右气泡展示，同时播放下行语音。
